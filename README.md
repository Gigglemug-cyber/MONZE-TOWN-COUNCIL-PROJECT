# Monze Town Council Dataset.

## CSC 4792 – Data Mining and Warehousing.

This repository contains the dataset, Jupyter Notebook, and Python scripts developed by Project Team 41 for the CSC 4792 Mini Project.

## Assigned Council.

Monze Town Council, Zambia

Official website: https://www.monzecouncil.gov.zm/

## Project Objective.

The aim of this project is to collect, clean, and organise publicly available information from Monze Town Council.

The dataset includes information such as:

- Constituency Development Fund (CDF) projects
- Council financial information
- Budget and expenditure records
- Development projects
- Council publications and reports

## Repository Contents

- `datasets/` – cleaned dataset files
- `raw_data/` – raw collected data
- `csc4792_team41_monze_dataset.ipynb` – Jupyter Notebook containing the data extraction, cleaning, and preprocessing process
- `monze_scraper.py` – website scraping script
- `extract_articles.py` – data extraction script
- `find_cdf_figures.py` – CDF data extraction script

## Dataset Format

The final dataset files are stored in CSV format.

The pipe character `|` is used as the column separator as specified in the project document.

## Data Source

All data was collected from publicly available information published by Monze Town Council.
